# ZINE STUDIO

单文件浏览器 Zine 编辑器及 V6.1 策划助手原型。

## 打开

- `zine-studio-v6.html`：稳定的 V6 编辑器。用浏览器直接打开即可。
- `zine-studio-v6.1-poc.html`：V6.1 策划助手 POC。先输入创作描述，体验最多 3 个关键追问、信息核对与策划初稿；页面下方可展开原有编辑器。

当前 V6.1 策划使用**规则模拟**，未调用真实 AI，也不会自动修改画布。策划大纲编辑、策划数据保存及策划到排版的联动仍在后续阶段。

## 当前能力

V6 支持全局图片池、动态页数、规则自动成册、布局切换、图片移动与缩放、文字与手绘编辑、JSON 项目保存恢复，以及通过浏览器打印为 PDF。V6.1 POC 增加策划引导，并改善自动成册的图片布局。

## 进度与设计

- `zine-v6.1-phase1-review-and-design.md`：V6.1 基线审查、数据结构和开发路线。
- `zine-v6.1-stage2-report.md`：策划助手 POC 的实现、测试、风险和后续阶段。
- 其他 `zine-v6-*.md`：V6 各阶段记录。

本仓库目前为可直接打开的 HTML 原型，尚无构建步骤。浏览器目视体验和完整交互仍需人工验收。
